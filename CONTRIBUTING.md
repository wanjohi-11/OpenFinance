# Contributing to OpenFinance

Contributions are welcome.

## Principles

1. Keep a fresh clone useful without paid APIs or private credentials.
2. Use synthetic data only.
3. Never commit secrets or personal financial information.
4. Keep provider integrations behind explicit server-side boundaries.
5. Preserve mobile usability and accessible semantics.
6. Update installation documentation when setup changes.

## Workflow

1. Fork the repository or create a branch.
2. Make a focused change.
3. Run PHP syntax checks on changed PHP files.
4. Test the relevant browser flows.
5. Open a pull request describing the problem, approach and test steps.
