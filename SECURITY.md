# Security Policy

OpenFinance is a public demonstration repository. It must not contain production credentials, private keys, access tokens, database passwords, or real member/customer information.

## Reporting

Do not disclose exploitable vulnerabilities, secrets, personal information or private infrastructure details in a public issue. Contact the repository owner privately through an appropriate GitHub profile contact channel.

## Demo boundary

The project intentionally omits production-grade identity, authorization, persistence, audit, payment, reconciliation and compliance controls. Every bundled financial record is synthetic.
